## 导航和场景边界

`navigation-plan.json`是依据五套正式拼图人工标定的可走多边形和阻挡区，碰撞与美术像素独立。采用每运行像素0.1世界单位、2单位网格，MSB优先、北向南行序；该比例仅用于本轮客户端，不是服务端地图登记。

21003有效矩形从半开像素边界`[672,920,2400,2216)`转换，保留室内地面并封闭墙、香炉、节庆摆件及外部填充。28007保留入口、主厅和中央圆台；门路未明确的侧室、后卧室和缺少高度契约的楼梯保守阻挡。35004保留三座分离云海石台，不新增桥梁，不允许跨云海寻路。可走格分别为3218、1481、2566，连通域分别为1、1、3；每图的春节和中秋导航字节完全一致。

## 使用入口

Unity菜单`MMORPG/Maps/节庆地图离线预览`会先询问保存当前场景，再打开`Assets/Scenes/World/FestivalMaps.unity`。点击Play后默认进入21003春节，可在左上切换三张地图及已交付外观，使用WASD或点击移动、滚轮缩放、F5切换人物。该场景复用正式地图构建器、资源加载器、导航、玩家控制器和相机，保持离线。

正式游戏中的“地图”窗口动态列出新地图、显示实际总览和春节/中秋选项；这三张地图的传送显示尚未开放。旧三张地图的联机流程保持现有场景编号。

```powershell
python tools/import_festival_maps.py verify
python -m unittest discover -s tools/tests -p test_import_festival_maps.py -v
python -m unittest discover -s tools/tests -p test_festival_map_navigation.py -v
```
