## 运行与测试位置

新加载器挂在正式地图实例上，由原有相机更新后的 `LateUpdate` 驱动。中心附近可见块优先，共享纹理池最多 8 块（含不可取消的在途请求），最多 2 个并发请求；离开范围两秒后释放，失败块十秒后可重试。RGB24 像素预算约 384 MiB，实际显存与设备帧率仍需实测。

主城出生点位于尚未交付的 r09_c08，出生脚下显示当前布局底图属于预期行为。主城已有分片主要在 r03–r06/c04–c07、r05–r08/c13–c15 等区域；以实际清单中的坐标为准，不代表这些矩形中的每个格子均已完成。清单从西北角开始，行列均从 1 计数。

其他电脑须检出 `Assets/Resources/World/CurrentMaps20261009` 并重新导入/构建客户端。所有运行资源为仓库内真实 PNG、JSON、文本及 `.meta`，运行不依赖美术仓库、临时传输文件或本机盘符。
