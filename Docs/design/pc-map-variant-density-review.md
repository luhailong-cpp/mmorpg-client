# 静态地图原版与高清版的等占地对照

41081 的旧双节图各为 4000×2600，10 列 9 行。新版目标为 11314×7354，总游戏占地仍为 4000×2600 个原图像素。按预览场景每 1024 个原图像素一个 Unity 单位，两版都占 3.90625×2.5390625 单位。旧客户端另外有一套 12 张 JPEG 的端游底图预览。比较双节画质时应选对应节日的原版。

## 目录与坐标

沿用静态地图目录、两节外观与相机。比较用目录放在独立验证工程的 `Assets/Resources/World/PcMapVariantReview/` 下，给旧版与新版各自建一份 catalog、一份来源记录及按节日分开的 tiles 清单和资源。将生成出的校验包放在客户端忽略目录，保留正式场景的目录引用。正式接入时大地图须按目标平台的分包方案加载。

独立目录的地图项与每节 tiles 清单都填写相同的 `worldGrid` 对象，四个整数字段为 `widthPixels`、`heightPixels`、`tileWidthPixels`、`tileHeightPixels`。41081 依次填 4000、2600、400、300。`nativeWidth/Height` 是当前连续图尺寸，`tileSize` 是每片各轴允许的最大像素数，独立目录用 2048。每个瓦片仍登记实际左上角、宽高、字节数、SHA-256 及资源路径。带世界网格的 tiles 清单用 schema 2。旧清单继续用 schema 1。

从左上角按原世界网格落位，每条公共边将原图坐标乘目标轴长再除以原轴长，四舍五入为整数。相邻片使用同一条公共边，底行只占 200 个原图像素。native 内容在原世界矩形内沿两轴分别缩放，低清总览 UV 从目标图取样，视野筛选、相机范围均按原世界坐标。目录与清单的网格、所有片矩形及完整覆盖应一致，有一处错误就拒绝该目录。

## 实测与采用

独立导入器路径对切片设 2048 上限、NPOT 原尺寸、无压缩、无 mip、Bilinear、Clamp。每个平台记录实际运行目标、导入尺寸、格式、质量档与缩放。离线预览使用同一个相机位置、同一画幅，对原版和候选抓取原生片加载完成后的画面。比对最近视角的栏杆、八卦图案、地砖跨片接缝及春节或中秋装饰。

先用 41081 旧图原尺寸裁片验证导入和几何，再用真实高清成图做同景两版对照。发布候选还需在正式 41081 场景的最近允许镜头和目标平台实测。保留原版与全部配套资源，采用资格由这些实测及美术验收决定。

## 重复抓取

在私有验证工程准备两个版本目录，登记各自的来源整图和原生分片 SHA-256。Play 时在 Project 面板选中独立目录的 catalog.json，通过「Assets → MMORPG → 用选中目录比较当前地图」切换；查看器保留同图位置和缩放。批量验收使用下列输入格式，资源路径省略扩展名，机位坐标为 Unity 预览世界坐标。

```json
{
  "mapId": "41081", "width": 2560, "height": 1080,
  "versions": [
    {"catalog": "World/PcMapVariantReview/41081/legacy-v001/catalog", "appearance": "spring"},
    {"catalog": "World/PcMapVariantReview/41081/review-hd-v001/catalog", "appearance": "spring"}
  ],
  "views": [{"worldX": 1.5625, "worldY": 1.220703125, "orthographicSize": 0.12}]
}
```

将配置保存为 JSON，以 Unity 可执行文件运行以下参数。每次抓取写入验证工程独立的 `Logs/PcMapVariantReview/<运行ID>/`。先验证清单、全部分片导入与当前视野精灵的实际边界，再记录相机抓图、色彩空间、质量档、实际 GPU 格式与帧缓冲尺寸。报告 `CAPTURED_FOR_REVIEW` 表示已取得画质对照材料。离线正交镜头下限为 0.12。

```text
-batchmode -projectPath <私有验证工程> -executeMethod MmorpgClient.Editor.CurrentMaps.PcMapVariantReview.RunBatch -pcMapReview <对照配置.json> -logFile <运行.log>
```

## 41081 实测记录（2026-11-24）

Unity 6000.6.0f1 在 Windows64 导入目标、Linear 色彩空间、Ultra 质量和 GTX 660 上读到了旧春节和中秋各 90 张切片。两版完整占地均为 3.90625×2.5390625。检查持续期间，客户端目录另行接入了旧双节，当前离线默认是旧春节，原 12 张 JPEG 通过日常外观访问。用于视觉比较的两张整图来自 image 项目的 `designs/client-map-41081-festivals-20261123-v001`。

真实高清中立素材 C-stair 中与原图 `(1200,1200)–(2000,1500)` 相同的区域横跨两片。导入后分别为 1132×849 与 1131×849，RGB24、GPU 格式 R8G8B8_SRGB、无压缩、单 mip。原版的此区域与原版完整地图在同机位拍到的 2560×1080 画面逐通道一致。高清样片可见阶面石纹、台缘雕线和柱帽造型。Android、iOS、WebGL 的检查设置都继承 2048 上限，本机仅安装 Windows 播放器支持模块。完整双节高清画面、设备与正式联机镜头留待实际成图和对应环境验收。
