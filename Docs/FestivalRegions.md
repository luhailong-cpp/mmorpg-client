# 蓬莱岛、东海渔村、揽仙镇地图接入

## 游戏入口

进入游戏后点击右侧“地图”或按 M，选择天墉城、蓬莱岛、东海渔村、揽仙镇，再点击“前往”。蓬莱岛可切换日景/中秋月夜，东海渔村可切换日景/元宵灯会，揽仙镇可切换日景/春节迎新。原天墉城可返程。

换地点调用正式 EnterSceneC2S，并等服务端入场通知；切换景色只更换当前地图材质贴图，保持场景实例、玩家实体、坐标和导航。战斗期间不能传送，地图窗口会阻挡角色输入。断线、超时、乱序回复和地图资源加载失败都有清理或失败处理。
