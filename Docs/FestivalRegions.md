## 当前验证与联机验收

可在任何检出客户端的机器执行：

```sh
python -m pip install Pillow
python tools/import_current_maps.py --verify
python -m unittest discover -s tools/tests -p test_import_current_maps.py -v
```

CI 在 Windows 和 Linux 上执行原图哈希、标注重建遮罩、跨平台字节保持和导入回归检查。当前本机已完成 C# 编译及生产导航代码的独立网格/寻路校验；这些检查不代表 Unity 内运行或真实联机通过。本机 Unity 编辑器无有效许可证，Docker 引擎未运行，正式播放器验收仍需在具备运行环境的机器完成。

在正式播放器的自动登录参数后加 `-currentMapVerify -currentMapVerifyOut <目录>`，可通过真实传送窗口循环游历三图，检查出生、贴图尺寸、导航、WASD、点击寻路及服务端回拉，并输出三张截图和 `current-map-verification.json`。从主城开始时顺序为 **2→3→1**；若已在其他图，则调整起点避免同图请求。使用可渲染的游戏窗口，以 `[CurrentMapVerify] RESULT` 和 JSON 的最终结果为准。兼容旧 `-festivalMapVerify*` 参数，但验收目标已改为这三张当前地图。
