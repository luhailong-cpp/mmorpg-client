# V12 人物八帧接入准备

代码已支持同一批角色按验收进度混用 V11 四帧与 V12 八帧。当前没有已激活的 V12 角色，游戏继续使用现有 V11 资源。

`QdaoCharacterCatalog` 在每角色的 `World/Characters/QdaoRosterV12/<ID>/appearance.json` 存在且有效时检查整套纹理。版本12、8帧、每帧60ms、独立站立、数值/视觉均passed、三份SHA-256验收标识、73张运行时纹理（64走路、8站立、1肖像）都满足要求，才启用该角色V12。任一条件不完整则保留同一ID的V11，不跳到其他人物。角色ID、职业/性别映射和存档不变。

世界动画器继续使用真实移动距离驱动每帧，不移动实体根节点。八方向均加载独立01–08纹理与idle/<DIR>站姿，V11仍保持01–04与接触帧站立。新八帧步态使用0或4号接触相位，与旧主角专用相位表分开。60ms×8与120ms×4都为480ms一轮；像素尺寸、脚底、朝向迟滞、渲染排序和阴影保持原约定。

战斗显示同一角色的独立站立与移动姿势。此升级不新增攻击、施法或受击原画。肖像与整套资源版本一起切换；未完成V12时仍显示同一人物V11肖像。身体、战斗和肖像缓存按ID、资源版本、验收修订和接触相位隔离。
