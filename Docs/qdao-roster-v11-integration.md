# 八位 Q 版人物接入与四帧拆分

本次接入使用已验收八人素材。每人八个方向，每方向四张独立动作图，共 256 张 512×512 RGBA 图片。世界和战斗的新人物加载路径均为 `World/Characters/QdaoRosterV11/<slug>/walk/<DIR>/01` 至 `04`，整张创建 Sprite；不会把四张再按八格切分，也不以重复图片凑帧数。

每个方向按 `01 → 02 → 03 → 04 → 01` 循环。在标准移动速度 9 世界单位/秒下，每张约 120ms；步频随实际移动距离变化。停止后至多完成一轮再停在当前方向的首张落脚图；新包没有另外绘制的中性待机姿势。原人物的八帧和独立待机资源继续保留兼容。
