# AI 协作约定与模型档位规定

> 对应根索引 [AGENTS.md AI 协作与模型档位](../../AGENTS.md#ai-协作与模型档位规定负责人确认于-2026-11-20)。新电脑或新 AI Agent 启动前请先完成必装 Skills 安装 → [required-skills.md](required-skills.md)。

在 [权限边界](naming-and-boundaries.md#2-禁止事项与权限边界) 内，AI 可编写客户端代码（C# / Shader / `.jslib` / PowerShell / Python 工具）、文档和自动化测试，执行代码评审与 UI 还原核查。不同 Agent 与模型档位按本文件分工协作。

## 1. 编码与编译 / 生成 / 测试分工

- **只负责客户端业务代码时（如 Claude Code 或编码会话），可修改源码、测试与文档，默认不直接跑协议生成、Unity 编译检查、客户端打包或运行期冒烟测试，交由 Codex（或低档执行会话）执行。**
- 编码方改完代码后，给出可直接执行的验证清单：
  1. **前置协议/配表步骤**：是否需先在服务端仓跑 `dev.bat proto` / `dev.bat gen`，再在本仓跑 `tools/gen_proto.ps1` / `tools/gen_messageids.ps1`；
  2. **具体编译与测试命令**：工作目录、`pwsh -File tools/client_compile_check.ps1`、受影响的 EditMode / PlayMode 测试脚本或 `-testFilter`、是否需先退出占用同一工程的 Unity 编辑器（Unity BatchMode 与打开同一工程的编辑器互斥）；
  3. **通过标准与证据路径**：期望输出、日志位置（`Logs/` 或 `.codex-artifacts/`）以及失败时需保留的首错原文。
- **严禁无证据宣称通过**：在拿到实际编译、测试或实机截图对比结果前，**不得声称“编译通过”“测试全绿”“已验证”或“与原图一致”**；交付说明须如实写明“未编译 / 未在 Unity 运行，待验证”。
- **Unity `.meta` 完整性**：在 `Assets/` 下新增、移动、重命名或删除任何文件/目录时，必须同步处理对应的 `.meta` 文件（移动/重命名须保留原 GUID 以免打断 Prefab / Scene 引用）。

## 2. 执行与安全写回流程

- **标准执行流**：完成会话启动门禁 → 检查 `git status -sb` 既有改动 → 明确改动范围与调用链 → 最小完整实现（含关联测试与 `.meta`） → 按分工执行构建/测试 → 汇报改动文件、验证证据、未验证项与剩余风险。未经用户明确要求不执行 `git commit`。
- **保护他人并发工作**：动手前先核查工作区既有未提交改动；**严禁覆盖、回退（`git checkout --` / `git reset`）或顺手格式化他人的在途文件**，不在功能改动中夹带任务外重构。
- **草稿副本写回主工作区规范（负责人 2026-11-10 定）**：当托管 worktree 已清理或桌面应用守卫拦截主工作区直接编辑、需在草稿目录修改副本再写回时：
  1. 写回前逐字节核对主仓目标文件是否仍与复制时一致；若主仓期间已被其他会话修改，必须用 `git merge-file` 做三方合并，出现冲突立即停下汇报；
  2. 追加型记录文档（如 `Docs/ClientProtocolCompatibility.md`）只做增量追加或定点更新，不覆盖他人新增段落；
  3. 写回后用 `git diff` 逐文件核对只包含本次预期改动，并在交付说明中注明写回方式。**禁止**跳过比对直接用重定向、`Move-Item -Force` 或 `Copy-Item -Force` 盲目覆盖主仓文件。
- **遇错保留现场**：命令报错时不假装成功、不盲目连续重试、不通过 `#pragma warning disable` / `[Ignore]` / 删断言 / 放宽像素容差来“变绿”。保留首错原文与日志路径，立即汇报。
- **触发红线立即停下**：当任务触及禁止手改目录、预计改动 30+ 个手写文件、规范与需求冲突、缺少效果图/字体/协议事实源、需要安装系统级工具、写密钥或执行 `git push` 时，立即停下等待负责人决策。

## 3. 模型档位规定（强制，负责人 2026-11-20 定）

- **修改代码必须使用各软件当时的最高档模型**，不得在低档模型上改代码：
  - Claude Code：`Fable 5.2 Max`
  - Gemini：`Gemini 4 Neon Extra`
  - Codex：`GPT 6.2 Astral Ultra`
- **编译、协议生成、跑测试与冒烟使用低档模型**（遇到需要改代码的报错先保留首错原文停下，切回最高档模型再改）：
  - Gemini：`Carbon Medium`
  - Codex：`6.1 Sol Ultra`
  - Claude Code：`Opus 5 High`（默认不跑构建命令，仅在负责人明确指定时用此档）
