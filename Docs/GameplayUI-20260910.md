# 背包、任务、活动 UI

2026-09-10，新增三页正式原生 uGUI 和主城入口。主城点击「背包 / 任务 / 活动」，或使用 B / J / O；输入文字时不触发字母快捷键。三个窗口共用一套玉绿、米白细金边、灯笼红绳与月兔饰件，并与人物、宝宝窗口互斥，进战斗或断线时收起。

## 已接入能力

- 背包：读取服务器真实实例与独立布局，按槽位分页，支持名称/编号搜索、装备分类、详情、货币和容量。打开与筛选不整理；只有玩家显式点「整理背包」才发送整理 RPC，服务端返回后刷新布局。
- 任务：真实目录和运行进度、状态筛选、任务分页、多目标分页与本地追踪。选择和追踪使用 `(scope, mission_id)`，避免不同作用域的同号任务串数据。
- 活动：真实活动目录、开放状态筛选、分页与详情；界面节庆装饰不决定活动排期。
- 数据层：复用 GameClient 传输，断线清快照，拒绝旧连接、旧角色和被后发请求覆盖的回包；保留失败前的有效快照并提示重试。
